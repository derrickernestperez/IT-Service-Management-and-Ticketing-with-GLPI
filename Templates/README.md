# Templates

This folder contains reusable IT service management templates for the GLPI homelab.

Planned templates include:

- Incident ticket template
- Service request template
- Problem record template
- Change request template
- User onboarding checklist
- User offboarding checklist
- Asset registration template
- Knowledge-base article template
- SLA definition template
- Post-incident review template

All templates must use fictional or redacted information.
