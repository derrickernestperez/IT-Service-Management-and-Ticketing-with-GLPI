# Scripts

This folder contains automation and validation scripts used in the GLPI homelab.

Planned scripts include:

- GLPI server health checks
- Database backup automation
- Configuration backup automation
- Asset inventory export
- Ticket report export
- Evidence-file validation
- Sensitive-information checks
- Final repository validation

Scripts must not contain:

- Passwords
- Database credentials
- API tokens
- Session cookies
- Private keys
- Personal information
