# Knowledge Base

This folder contains reusable support articles created for the GLPI homelab.

Planned articles include:

- How to reset an Active Directory password
- How to unlock a user account
- How to register Microsoft Authenticator
- How to troubleshoot a printer
- How to troubleshoot DNS resolution
- How to report a phishing email
- How to resolve a Windows Update failure
- New employee onboarding guide
- Employee offboarding guide
- Common help desk troubleshooting commands

All articles must use fictional or redacted information.
