# Ticket Scenarios

This folder contains realistic IT service desk simulations created in GLPI.

Planned ticket scenarios include:

- Active Directory account lockout
- Password reset request
- New employee onboarding
- User offboarding
- Printer offline incident
- Windows Update failure
- Microsoft Authenticator registration issue
- Suspicious MFA request
- DNS resolution issue
- Laptop hardware failure
- Network outage
- Priority-one server outage

Each scenario should document:

- Ticket type
- Category
- Impact
- Urgency
- Priority
- Assigned technician
- Troubleshooting steps
- Work notes
- Resolution
- User confirmation
- Closure status
- Related asset
- Evidence reference

All users, devices, organizations, and ticket details must be fictional or redacted.
