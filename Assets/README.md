# Assets

This folder contains the fictional IT asset records used in the GLPI homelab.

Planned asset types include:

- GLPI application server
- Domain controller
- Microsoft Entra Cloud Sync server
- Windows client workstation
- Administrator workstation
- Laptop
- Printer
- Network switch
- Router
- Monitor
- Installed software
- Software licence records

Each asset record may include:

- Asset tag
- Asset type
- Manufacturer
- Model
- Serial number placeholder
- Assigned user
- Department
- Location
- Operating system
- Status
- Purchase date
- Warranty date
- Related support tickets
- Notes

All asset names, serial numbers, users, departments, and locations must be fictional or redacted.
